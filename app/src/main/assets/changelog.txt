- Versions now use simple major.minor.patch numbers instead of date-based names.
- The assistant continues after running tools, retains their results for follow-up questions, and reports empty provider replies instead of silently stopping.
- The assistant now uses structured tool calls and receives each tool result directly, with support for streaming and Claude.
- Switching or clearing chats stops the current reply so it cannot overwrite another conversation.
- Chat saves preserve the previous messages if a save fails.
- New backups use a password and include attached images so they can be restored on another device.
- Large image attachments are resized to reduce memory use.
- Shell execution is disabled to keep tools within their allowed storage folders.
- Provider switching keeps API keys separate, and custom provider endpoints are used correctly.
- Copying or importing a file onto itself no longer risks damaging its contents.
