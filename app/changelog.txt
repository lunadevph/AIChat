- You can add your own provider. Any OpenAI-compatible endpoint works: give it a name and base URL in Settings → AI & Provider → API Keys → Add provider, with an optional description, key prefix, model list and default model. Custom providers appear in the setup picker and the key manager like the built-ins, can be set active, and can be removed again.
- A custom provider without a hand-written model list has its catalog fetched from the endpoint, exactly like the built-in ones.
