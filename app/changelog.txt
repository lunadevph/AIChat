- When the assistant saves a file whose contents include a code block, the code is now saved with the file instead of being dropped, and a tool tag that it is only showing you inside a code block is no longer run.
- The assistant can now use tools. It can read and write files in a private workspace, list and search them, delete them, save or read its own memory, compact that memory, search the web and look up the date and time — all by writing simple tags such as <read path="notes.md"/> in its reply.
- Every tool the assistant runs is shown as a small pill above its reply, so you can see what it did.
- AI settings has a new "Tool calls" switch to turn the assistant's tools off, and a "Tool workspace" row showing the files it has written, with a button to clear them.
- Saving memory now uses a <memory> tag, and <compact/> shrinks memory when it has grown repetitive.
- The chat header is now a Material 3 Expressive flexible app bar that shows the current model as its subtitle and folds away as you scroll.
- The composer now uses an expressive split button: one half sends (or stops), the other opens the attach menu, and web search is a toggle button beside the input.
- Loading states use the Material 3 Expressive morphing loading indicator, and update checks use the wavy progress indicator.
- The empty chat screen uses shapes from the Material shape library, and headings use the expressive type styles.
- Removed the OpenCode Zen provider; it is no longer offered in setup, settings or the model picker.
- If you had OpenCode Zen selected, the app now falls back to the default provider instead of staying on the retired one.
- All user-facing text now comes from translatable string resources, including the update, setup, settings and about screens.
- A failed model-list refresh no longer replaces the full model catalog with a short built-in list, and no longer resets your chosen model.
- A generated chat title can no longer be written to the wrong conversation if you open another chat while it is being created.
- The chat now scrolls to new replies in one smooth motion instead of two competing scrolls.
- Conversations, messages and models keep their identity when lists change, so the chat and pickers no longer reshuffle.
- Copying a code block that has no body no longer copies the language name instead.
- Accessibility: the back arrow, API-key show/hide toggle and switch states are announced correctly, and logos are no longer read twice.
