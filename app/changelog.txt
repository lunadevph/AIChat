- The launch screen now follows the system light/dark setting instead of always being black, and the status and navigation bar icons match the theme instead of staying white in light mode.
- Elements that used raw colour values instead of the dynamic palette now take theirs from the theme file — theme swatches in Settings show the actual palette, and the window background matches the launch screen.
- The assistant can now read, search, write, move, copy and delete in your shared folders (`/storage/emulated/0/…`) with absolute paths, not just copy files into its private workspace. One rule for every file tool: a relative path means the workspace, an absolute one means your device. Deleting a shared root itself is refused.
- Five new tools: `<replace>` (regular-expression replacement, with `<edit>` staying literal), `<find>` (locate files and folders by name pattern), `<stat>` (size, dates, line count and permissions of one file or folder), `<tail>` (the last lines of a log or long document) and `<storage/>` (where the assistant can read and write, and how much room is left). Searches can be limited to one folder.
- NVIDIA NIM is the ninth provider: Nemotron and hosted open models through `integrate.api.nvidia.com`, with its own mark in the picker.
- The update mirror now carries its format version, a release timestamp, the APK's size and SHA-256, an optional minimum supported build, and a provider icon for NVIDIA. The downloaded update is checked against that hash before it is offered to the installer, and a build below the minimum is forced to update.
- Every field a previous version of the app already reads is unchanged, and the new ones default sensibly, so an old build keeps updating from a new mirror.
