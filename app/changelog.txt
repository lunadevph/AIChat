- The top bar is back to a plain centred bar: the app's mark, the name and the current model sit together in the middle, with the menu button on the left and the overflow menu on the right. The tall flexible bar is gone.
- The app's mark is back to the flat rounded tile it used before, on every screen, instead of the gradient blob — and the empty chat screen no longer has a second shape peeking out behind it.
- Rate limits are no longer an error. When a provider answers "too many requests", the app waits and tries again by itself — 2 seconds, then 4, 8 and 16, or however long the provider asks for — and shows the countdown where "AI is thinking" normally appears. Stopping the reply still cancels it.
- The rate-limit message now only appears after several retries have failed, and says the provider is still busy rather than asking you to wait a moment.
- When a provider rejects a reply for using its own tool-call format — Groq's "Tool choice is none, but model called a tool" — the app now asks once more, telling the model to use the plain tags this app understands, instead of failing your message.
- The tool instructions now tell the model outright never to use a provider's native function-call syntax, which is what triggers that rejection.
- If it still fails, the error now says what to do: turn off Tool calls in Settings → AI settings, or choose a different model.
