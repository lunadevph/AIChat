- The model picker has been redesigned: your provider's logo sits at the top, the model you are using is shown in a pill beneath it, and the list below is much denser, so far more models fit on screen at once.
- The model picker now shows how many models match what you are searching for.
- The app's logo is the same mark everywhere — drawer, chat header, empty chat screen, setup and about — on a soft gradient blob instead of the old flat square.
- The whole interface is more compact: tighter chat rows, message spacing, settings rows, model and provider lists, and a slimmer composer, so more fits on screen without shrinking anything you tap.
- The assistant can now do a lot more with your files: <cat> reads one, <edit> changes part of one, <append> adds to the end, and <mkdir>, <move> and <copy> manage folders and duplicate files.
- The assistant can also work with the internet and your device: <download> saves a file from a link into its workspace, <fetch> reads a web page as text, <upload> copies a file from your device in, and <open> opens a file it made in your own viewer.
- There is a new "Tool files" screen listing every file the assistant has written — with its size, when it was last changed, a preview you can select and copy, a delete button, and one button to clear them all.
- In the chat, tapping a tool pill now opens a small panel showing the file that reply touched, with a button to view it.
- AI settings has a new "Device storage" switch. Off by default, it lets the assistant read and save files in your shared folders (Downloads, Documents, pictures) instead of only its own workspace.
- The app now updates itself: it downloads the new version inside the app with live progress and hands it to the installer, instead of opening a download page in your browser. There is still a button to open the download page if you prefer.
- If Android needs your permission before it will install the update, the update screen explains it and takes you straight to the setting.
- Setup is now a clear three-step flow with a progress row, a note that your key never leaves the device, a proper "checking your key" and "you're connected" state, and a way to save your key and continue anyway when your provider cannot be reached.
- The app now names itself properly in the task switcher and recents screen instead of showing hard-coded text on those screens.
